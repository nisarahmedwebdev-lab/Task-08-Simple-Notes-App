# Task-08-Simple-Notes-App

✨ Features
<br>
📝 Create Notes - Add notes with title, content, and color

👁️ View Notes - Display notes in a responsive grid layout

✏️ Edit Notes - Update note content with instant UI refresh

🗑️ Delete Notes - Remove notes with sweet confirmation dialog

🎨 Color Coding - Choose from predefined colors for visual organization

📅 Date-wise Sorting - Newest notes appear first

🔄 Real-time Updates - AJAX operations without page reload

📱 Responsive Design - Works on desktop, tablet, and mobile

✅ Form Validation - Both client-side and server-side validation

🎯 Icons Support - Font Awesome icons for better UI

💬 Sweet Alerts - Beautiful confirmation and notification dialogs
